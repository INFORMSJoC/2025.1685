# Results

## Tables

- `table_3_small_instances.xlsx`: raw and selected results underlying Table 3.
- `tables_3_4_response_search_raw.xlsx`: serial/parallel RS preprocessing and
  optimization records used in Tables 3 and 4.
- `table_4_medium_instances_raw.xlsx`: final medium-instance solver records for Table 4.
- `table_5_large_instances_raw.xlsx`: Cuts/RS records underlying Table 5.
- `table_5_response_search_cuts_raw.xlsx`: RS, RS+Cuts, and stability-enhanced
  raw records used in Table 5.
- `tables_6_8_case_study.xlsx`: the exact values reported in Tables 6-8.
- `table_9_callback_comparison.xlsx`: the exact values reported in Table 9.

## Figures

- `figure_3/`: stochastic bilevel, deterministic bilevel, and stochastic
  single-level network designs.
- `figure_4/`: response-search iteration distributions for the six medium instances.
- `figure_5/`: stochastic bilevel designs for `theta = 0.002` and `0.005`.

## Raw files

- `raw/figure_4/`: iteration-count JSON files used by the Figure 4 script.
- `raw/case_study/`: saved `x`, `y`, and `z` solutions for the three reported
  theta values and five model configurations, plus the corresponding solution
  detail workbooks.
